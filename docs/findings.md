# Hallazgos: convenciones y riesgos

Fase 2 del análisis del repo. **Fuentes:** `verification.md`, `AGENTS.md`, `README.md` / `README.es.md` y el código fuente. Todo se obtuvo leyendo archivos: no se ejecutó nada ni se modificó código.

**Leyenda**

- **Tipo**: **C** = convención existente que conviene respetar · **R** = patrón arriesgado para futuras ediciones · **C+R** = convención con un riesgo asociado.
- **Verificación**: *lectura* = comprobado por el agente leyendo archivos · ✅ = confirmado en ejecución por la usuaria (se cita la fila de `verification.md`) · ❓ = nadie lo ha comprobado. Cuando se indica, la fila incluye cómo comprobarlo.
